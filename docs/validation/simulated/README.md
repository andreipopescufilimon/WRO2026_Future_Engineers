# Simulated test-log examples, not physical observations

All populated numerical data in this directory was generated for demonstrating CSV formats, plotting, parser behavior and the level of detail to record during real experiments.

**None of these rows was measured on HyperLine Robotics V4.1.** The realistic values, timestamps, test identifiers, detection outcomes and success counts are fictional. Each record is labeled as simulated or synthetic. `sign_height_trials.csv` is a hypothetical camera-image geometry example, not a measured OpenMV classification test.

Use the physical/ directory for experiments on the real robot. Simulated results must not be submitted as physical WRO performance evidence. Do not merge them into the physical test files.
