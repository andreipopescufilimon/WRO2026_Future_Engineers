# Source-derived values and physical test scope

The source configuration tables list controller constants (pins, thresholds, servo commands, ToF addresses), not actual measured outputs. The source commit in a CSV is a reference checkpoint. Record the actual **flashed** Git commit in each physical test entry independently.

A physically verified test record should include original serial logs or photos/video, a date, hardware revision, exact flashed software commit and observed behavior. A test result label without these is not enough for independent WRO judging.
